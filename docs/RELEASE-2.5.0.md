# Whale Companion 2.5.0 · DSH 桌宠插件

面向 Windows 上的 DeepSeek Harness，保留桌宠互动、待办、提醒、专注、新闻、称呼、签到、成就，以及原有 HTTP v1/v2 和 17 个 MCP 工具。

## 安装

1. 预先安装 DSH 并建立 desktop profile。
2. 下载 `whale-dsh-2.5.0.zip`，完整解压。
3. 双击 `Install-DSH.cmd`，完成后重启 DSH。

重复运行可升级，安装器备份并保留用户数据。无需为 ZIP 安装另行安装 Python 或 Node.js。

## 附件

- `whale-dsh-2.5.0.zip`：双击安装包。
- `whale-dsh-source-2.5.0.zip`：DSH 插件与 Windows 桌宠源码。
- `dsh-whale-notify-2.5.0.tgz`：带完整运行时的 npm 格式离线包，未发布到 npm 注册表。
- `SHA256SUMS.txt`：附件完整性校验。

安装、升级与卸载见 [安装说明](https://github.com/jeagsdg/whale-companion/blob/main/docs/DSH-RELEASE.md)。MIT 许可及上游归属保留。
